# 뼈튼튼, 주사안심!

골다공증 환자와 보호자가 질환과 테리파라타이드 자가주사 치료를 쉽게 이해하고, 위험요인과 교육내용을 확인하며 건강기록을 관리할 수 있도록 만든 정적 웹사이트입니다.

## 주요 기능

- 골다공증 정의, 골절 위험, 검사, 예방과 치료 안내
- 테리파라타이드와 제품별 주사기구 구분, 공통 안전 투여 순서
- 보관·폐기·이상반응·응급상황 안내
- IOF 자료를 바탕으로 한 비진단성 위험요인 자가체크
- 주사 안전 OX 퀴즈
- 브라우저에만 저장되는 투약·이상반응·병원 방문 건강수첩
- CSV 내보내기, 인쇄, 전체 삭제
- 큰 글자, 키보드 탐색, 반응형 화면, 브라우저 음성 읽기

## 개인정보와 의료정보

- 회원가입, 서버, 분석 도구, 광고, 쿠키가 없습니다.
- 건강수첩은 `localStorage`의 `boneCareJournal.v1` 키에만 저장되며 서버로 전송되지 않습니다.
- 브라우저 저장 데이터는 암호화되지 않으므로 공용·공유 기기에서는 사용 후 기록을 삭제해야 합니다.
- 자가체크 응답과 퀴즈 결과는 저장하지 않습니다.
- 이 사이트는 환자교육 자료이며 진단, 처방, 의료진의 대면 교육 또는 제품별 사용설명서를 대신하지 않습니다.

## 로컬 실행

별도의 빌드 과정이 필요하지 않습니다. 저장소 루트에서 정적 파일 서버를 실행합니다.

```powershell
python -m http.server 4173
```

브라우저에서 `http://localhost:4173/`을 엽니다. `file://`로 직접 열 수도 있지만 로컬 저장소와 보안 정책 검증에는 HTTP 서버 사용을 권장합니다.

## 배포

GitHub Pages 설정에서 `main` 브랜치의 저장소 루트(`/`)를 배포 소스로 선택합니다. 모든 사이트 자산은 프로젝트 Pages 하위 경로에서도 동작하도록 상대경로를 사용합니다.

## 권리 안내

코드와 콘텐츠에는 별도의 오픈소스 라이선스를 부여하지 않았습니다. 원본 교육자료의 이미지·PDF·동영상은 재배포 권한이 확인되지 않아 이 저장소에 포함하지 않았습니다.
